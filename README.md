# Autonomous-line--following-Robot
Designing an autonomous robot from simulation to hardware using Eda playground,verilog,and kicad
#1 OVERVIEW 
this project implements an autonomous line-following and obstacle-avoiding robot using verilog ,simulated in Eda playground,and later implemented with a custom PCB designed in kicad.

## FEATURES
. Line following
. obstacle detection
. Motor control
. verilog stimulation
. Pcb design
. Hardware Implementation

### TOOLS
. Verilog HDL
. Eda Playground
. KiCad
. github
